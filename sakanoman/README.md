# SakanOman (سكن عمان) - Property Rental Platform

A modern, responsive web application for finding and listing rental properties across Oman. Built with Next.js, TypeScript, and Tailwind CSS.

## 🏠 About SakanOman

SakanOman is a comprehensive property rental platform designed specifically for the Omani market. It connects property seekers with verified landlords and agents across major cities including Muscat, Sohar, Salalah, and more.

## ✨ Features

### Core Functionality
- **🔍 Advanced Search & Filters**
  - Location-based search (cities across Oman)
  - Property type filtering (rooms, studios, apartments, villas)
  - Price range selection
  - Gender preference filtering
  - Furnished/unfurnished options

- **🏘️ Property Listings**
  - Detailed property descriptions with photos
  - Verified landlord badges
  - Rating and review system
  - Property type categorization
  - Location mapping

- **💬 Direct Communication**
  - WhatsApp integration for instant contact
  - Direct messaging with property owners
  - Contact verification system

- **👤 User Management**
  - Dual user roles (Seekers & Listers)
  - Email/phone verification
  - User profiles with photos
  - Property favoriting and sharing

### Modern UI/UX
- Responsive design for all devices
- Beautiful gradient backgrounds and animations
- Intuitive search interface
- Modern card-based property listings
- Smooth transitions and hover effects

## 🛠️ Tech Stack

- **Frontend**: Next.js 15 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Icons**: Heroicons React
- **Development**: Turbopack (for faster development)
- **Linting**: ESLint with Next.js config

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- npm or yarn package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/sakanoman.git
   cd sakanoman
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000) to see the application.

### Available Scripts

- `npm run dev` - Start development server with Turbopack
- `npm run build` - Build the application for production
- `npm run start` - Start the production server
- `npm run lint` - Run ESLint for code quality
